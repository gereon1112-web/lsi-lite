# Dokumentation LSI Lite

Hintergrund zu LSI Lite; wie man es benutzt, steht im [Haupt-README](../README.md).

| Ich möchte … | Dokument |
| --- | --- |
| verstehen, wie es rechnet | [verfahren.md](verfahren.md) |
| wissen, was gegenüber dem Original-LSI fehlt | [verfahren.md#was-vereinfacht-ist](verfahren.md#was-vereinfacht-ist) |
| finden, wo ein Schritt im Code steht | [verfahren.md#wo-es-im-code-steht](verfahren.md#wo-es-im-code-steht) |
| Messwerte sehen | [ergebnisse.md](ergebnisse.md) |
| wissen, warum es so gebaut ist | [entscheidungen.md](entscheidungen.md) |

- **verfahren.md**: die sechs Schritte von FEM-Ergebnis bis G-Code, wo sie im Code stehen, und die Vereinfachungen gegenüber dem LSI.
- **ergebnisse.md**: Vergleich mit dem Original, Wirkung der 5 Stufen, Versuch mit freier Unterseite, Nachglätten der Mittelschicht, Schichtrand am echten Abstand.
- **entscheidungen.md**: Entscheidungen mit verworfenen Wegen, zuletzt die Aufteilung in `bausteine/`.
